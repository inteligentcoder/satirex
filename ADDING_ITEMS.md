# Adding new items (frames, fonts, avatars, banners)

Cosmetics are stored in the `items` table and rendered by the frontend. There are
two ways to add one:

1. **Admin dashboard** (no code, instant) — recommended while experimenting.
2. **Seed script** (code, ships with the app) — for items that should exist on a
   fresh install.

An item has a **type**:

| type     | What it does | Key field used |
|----------|--------------|----------------|
| `frame`  | Animated/static ring overlaid on the avatar | `asset_url` |
| `font`   | CSS font-family applied to the user's posts & comments | `font_family` |
| `avatar` | Ready-made profile picture | `asset_url` |
| `banner` | Profile header image | `asset_url` |

Users can **equip** frames/fonts (stored on `User.frame_key` / `User.font_key`) and
avatars/banners (copied into `User.avatar_url` / `User.banner_url`).

---

## Option A — Admin dashboard (fastest)

1. **Log in as an admin** (seed account `admin` / `admin1234`, or set
   `ADMIN_USERNAME` / `ADMIN_PASSWORD`). An **Admin** link appears in the nav.
2. **Get an asset URL.** Either
   - paste an external URL to an image/GIF, **or**
   - upload your file first:
     ```bash
     curl -X POST http://localhost:8000/api/upload \
       -H "Authorization: Bearer <ADMIN_TOKEN>" \
       -F "file=@my_frame.gif" \
       -F "kind=frame"
     # -> {"url": "/uploads/frames/<hash>.avif", ...}
     ```
     Use the returned `url` as the item's `asset_url`.
3. **Admin → Shop items → fill the form → Create item.**

   | Field | Notes |
   |-------|-------|
   | `key` | unique slug, `[A-Za-z0-9_-]`, e.g. `frame_diamond` |
   | `name` | display name |
   | `type` | `frame` / `font` / `avatar` / `banner` |
   | `price` | fake money; `0` = free |
   | `asset_url` | for frame/avatar/banner (e.g. `/uploads/frames/x.avif`) |
   | `font_family` | for fonts, e.g. `'Impact', 'Arial Black', sans-serif` |
   | `Admin only` | hidden from normal users |
   | `Default` | granted to everyone on sign-up (make `price` 0) |

4. The item appears in `/shop` immediately. Users buy it, then **Equip** it on
   their profile.

## Option B — Seed script (ships with the app)

Edit `backend/app/seed.py`.

### Bundled frame asset

`generate_assets()` in `seed.py` writes animated GIF frames into
`backend/uploads/assets/frames/`. Add an entry to the `frames` list:

```python
frames = [
    ("classic", "#9aa4b2", "#e2e8f0", False),
    ("gold",    "#ffb300", "#fff3b0", False),
    # key,   ring color, pulse color, rainbow?
    ("diamond", "#7dd3fc", "#ffffff", False),   # <-- new
]
```

Then register the item in `seed_items()`:

```python
ensure_item(
    db, "diamond",
    name="Diamond Frame", type="frame", price=2500, sort_order=5,
    asset_url=_url(FRAMES / "diamond.gif"),
    description="Ice cold.",
)
```

Delete the generated file (or the whole `backend/uploads/assets/frames/`) and
restart the API to regenerate. `ensure_item` is idempotent, so existing items are
left untouched.

### Font item

```python
ensure_item(
    db, "font_times",
    name="Times Classic", type="font", price=200, sort_order=5,
    font_family="'Times New Roman', Times, serif",
    description="Old money energy.",
)
```

### Avatar / banner item

```python
# avatar generated by make_avatar into uploads/assets/avatars/
ensure_item(
    db, "avatar_mint", name="Mint Gradient", type="avatar",
    price=250, sort_order=4, asset_url=_url(AVATARS / "avatar_mint.avif"),
)
```

To add a new avatar/banner, add it to the `avatars` / `banners` dicts in
`generate_assets()` with two hex colors.

## Using your own assets (recommended for frames)

Frames are drawn as a square image with a **transparent center**, then overlaid on
the avatar by `frontend/src/lib/components/Avatar.svelte`.

Requirements:

- **Square**, ideally 256×256 or 512×512.
- **Transparent center** so the avatar shows through (the ring sits near the edge).
- Formats: **GIF** (animated), **WebP**, **AVIF**, or **PNG**. Uploads are
  auto-compressed by the API (animated frames → animated AVIF/WebP).
- Keep the ring inside the canvas (roughly 90–96% of the width) so the avatar's
  inset circle lines up.

Place your file in `backend/uploads/assets/frames/` (or anywhere under
`backend/uploads/`) and reference it as `/uploads/assets/frames/my_frame.gif`, or
upload it through `/api/upload`.

Fonts need no file — just a `font_family` value. Prefer web-safe/system families
(`Georgia`, `'Courier New'`, `Impact`, `'Comic Sans MS'`, `'Times New Roman'`) so
no external font download is required. You can also add a Google Fonts `<link>` in
`frontend/src/app.html` and reference that family.

---

## How rendering works (so new items look right)

- **Frames**: `Avatar.svelte` renders the user's avatar as a circle inset ~6% and
  overlays `user.frame.url` on top with `object-contain`.
- **Fonts**: `PostCard.svelte` and comments apply
  `style="font-family:{user.font.family}"` to the text.
- **Avatars / banners**: profile page uses `user.avatar_url` / `user.banner_url`.
- The API resolves `user.frame` / `user.font` from `frame_key` / `font_key`
  (`backend/app/serializers.py`).

---

## Equip rules

- A user must **own** an item (a `user_items` row) to equip it, unless the item is
  `is_default` or the user is an admin equipping an `is_admin_only` item.
- Frames/fonts are stored by `key`; avatars/banners copy the asset URL.
- `POST /api/shop/equip {"key": "<item key>"}` equips; `POST /api/shop/unequip
  {"key": "frame"}` (or `"font"`) removes it.

## Direct database example

If you prefer SQL (MariaDB/SQLite), insert an item directly:

```sql
INSERT INTO items
  (key, name, type, description, price, asset_url, font_family,
   is_active, is_default, is_admin_only, sort_order)
VALUES
  ('frame_diamond', 'Diamond Frame', 'frame', 'Ice cold.', 2500,
   '/uploads/assets/frames/diamond.gif', NULL, 1, 0, 0, 5);
```

Then the item shows up in the shop on the next page load (there is no cache).

## Troubleshooting

- **Frame doesn't show** — the user must own it and equip it; check
  `user.frame_key` and that `asset_url` resolves (visit it directly in a browser).
- **GIF not animating after upload** — the server converts to animated AVIF, which
  modern browsers animate. If your ffmpeg/Pillow build can't, it falls back to
  animated WebP.
- **Font has no effect** — verify the exact `font_family` string and that the font
  exists on the viewer's machine (or is loaded via a `<link>`).
- **Item missing for regular users** — it may be `is_admin_only` or `is_active = 0`.
- **New seeded item didn't appear** — assets are only regenerated when the target
  file is absent; delete the file (or `uploads/assets/*`) and restart.
